RBI GUIDELINES: NATIONAL ELECTRONIC FUNDS TRANSFER (NEFT)

1. AVAILABILITY
NEFT has been available 24x7x365 (including weekends and bank holidays) since
December 16, 2019, per RBI Circular RBI/2019-20/125 (DPSS.CO.RPPD.No.2/04.03.001/
2019-20). Prior to this circular, NEFT operated only during banking hours on
working days in half-hourly batches. The 24x7 rollout was one of RBI's key
digital payments modernization initiatives, aligning NEFT with the always-on
availability of IMPS and UPI.

2. TRANSACTION LIMITS
- No minimum amount — even Re 1 can be transferred via NEFT.
- Maximum amount per transaction: Rs 10,00,000 (Rs 10 lakh) for retail
  customers of most banks, though this is a bank-level cap, not an RBI-mandated
  ceiling; some banks permit higher limits for corporate/current accounts.
- There is no cap on the number of NEFT transactions a customer may initiate
  in a day, subject to the originating bank's own risk and channel limits.

3. BATCH PROCESSING
Although marketed as "24x7," NEFT is technically a deferred net settlement
(DNS) system, not real-time gross settlement. Transactions are collected and
processed in batches every 30 minutes, with 48 half-hourly batches running
from 00:30 to 00:00 the following day. A transaction submitted at 10:07 AM,
for example, is picked up in the 10:30 AM batch.

4. CHARGES
Per RBI mandate effective January 1, 2020, banks must not charge savings
account customers for NEFT transactions initiated online (internet banking
or mobile banking). Charges may still apply for NEFT transactions initiated
through a bank branch, and for current/corporate accounts, subject to each
bank's tariff schedule.

5. NEFT REFERENCE NUMBER FORMAT
Each NEFT transaction is assigned a unique transaction reference number (UTR)
generated by the sending bank, typically in the format:
  <Bank IFSC prefix><YYYYMMDD><sequence>
e.g., HDFCN52025010112345. This reference number should be quoted in all
customer-service and reconciliation communication.

6. BENEFICIARY CREDIT TIMELINE
The beneficiary's bank is required to credit the beneficiary account within
the same batch cycle in which the funds are received, or return the
transaction with reason codes if credit cannot be effected (see below). In
practice, once a batch settles at RBI's NEFT clearing centre, beneficiary
banks must credit or return within 30 minutes of settlement.

7. NEFT RETURN / REJECTION REASONS
Common reasons a beneficiary bank returns an NEFT transaction:
- Invalid or closed beneficiary account number
- Account holder name mismatch (where name-matching is enforced)
- Beneficiary account frozen, dormant, or under a debit freeze
- Invalid or non-existent IFSC code
- KYC-related restrictions on the beneficiary account
- Beneficiary bank branch NEFT-disabled
Returned NEFT amounts must be credited back to the remitter's account,
typically within the same day, and the remitting bank must not levy any
charge for the return.

8. IFSC CODE VALIDATION RULES
The Indian Financial System Code (IFSC) is an 11-character alphanumeric code
that uniquely identifies a bank branch participating in NEFT/RTGS/IMPS:
- Characters 1-4: Bank code (alphabetic), e.g., HDFC, ICIC, SBIN
- Character 5: Always "0" (zero), reserved for future use
- Characters 6-11: Branch code (alphanumeric)
Example: HDFC0001234. Remitting banks and payment processors must validate
the IFSC against the RBI/NPCI-published master list before accepting a
transaction for processing, to reduce return rates.
